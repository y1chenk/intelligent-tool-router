# Host and product profile (conditional examples)

Read this only when a named host/product matters. This is not a dependency list, current-installation claim or a set of hardcoded endpoints. Reconfirm schemas, permissions, availability and advertised costs.

- Context7 can supply version-matched docs after library resolution; official direct docs remain eligible.
- GitHub and equivalent providers expose only granted repository scopes.
- Firecrawl/Tavily-style readers can extract a known URL; choose crawling only for a relevant multi-page gap.
- Consensus-style literature discovery and Scite-style citation context support, rather than replace, original-paper inspection.
- Hugging Face-style model/dataset records require revision, license and file inspection appropriate to the task.
- Ahrefs/Semrush figures may be estimates; authorized GSC/GA4-style properties supply measured owned-site data. Hunter-style domain/email capability does not imply arbitrary company discovery.
- Railway/Vercel/Render/Supabase-style status/log/config operations should match the actual provider and target.
- Browser fallback, authentication, image editing, account files and skill/plugin persistence follow current host rules. For OpenAI product questions in an OpenAI host, inspect supplied local guidance and use official OpenAI sources as required; other hosts follow their own guidance.
- Wallet-metered tools such as TinyFish require respecting advertised billing constraints and existing spend authorization.
- Reuse an already-read skill at the same revision; a changed version or missing context permits a new read. Personal and plugin copies with the same name/version are one workflow, not instructions to load twice.

Do not use this file to assume device access, install integrations, change permissions or claim performance gains.
